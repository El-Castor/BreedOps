# Phenotyping and selection

Phenotyping measures observable traits. Selection uses those measurements to
support decisions.

A weighted score is a **decision rule**, not a universal biological truth.
Weights and eliminatory thresholds should reflect an explicit breeding
objective.

An eliminatory criterion represents a requirement that should not be
compensated by strong performance elsewhere.

Always distinguish:

- observed performance;
- repeatability;
- stability;
- selection index;
- genetic value.

BreedOps deliberately avoids relabelling one as another.
