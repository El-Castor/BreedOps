# Glossary

**Accession** — external identifier for biological material.

**Archive** — reversible removal from active workflows while retaining history.

**Criterion** — trait/rule used in a selection model.

**Environment** — defined experimental context, typically site × campaign or a
similarly explicit unit.

**Evaluation** — a dated set of phenotype observations.

**Family** — progeny group derived from a cross.

**G×E** — genotype × environment interaction.

**MGIDI** — Multi-Trait Genotype-Ideotype Distance Index.

**MTSI** — Multi-Trait Stability Index.

**Phenotype** — observed trait/expression of material under given conditions.

**Programme** — principal BreedOps container for a breeding activity.

**Seed lot** — physical seed batch linked to breeding lineage.

**Trait** — defined measurable/recordable characteristic.

**WAASB/WAASBY** — stability/performance approaches based on AMMI-related
interaction effects and weighted performance/stability.
