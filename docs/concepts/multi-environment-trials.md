# Multi-environment trials

A multi-environment trial studies how entries perform across environments.

If entries are true genotypes, the changing relative response across
environments is commonly discussed as genotype × environment interaction
(G×E). If entries represent families, populations or other material, use the
more general Entry × Environment interpretation.

Different models emphasize different questions:

- mixed models: variance components and predictions;
- AMMI/GGE: interaction structure and visualization;
- WAASB/WAASBY: stability and performance;
- Finlay–Wilkinson: response to an environmental index.

Interpretation should follow the experimental design, not only the software
output.
