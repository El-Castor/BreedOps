# 3 — Create your first programme

A **programme** is the main scientific/operational boundary used to organize
breeding material, traits, trials and analyses.

## Before creating it

Prepare:

- programme name;
- short programme code;
- species;
- campaign or season if relevant.

Choose a code that is stable and short. It becomes part of automatically
generated BreedOps record codes.

## In BreedOps

1. Open the overview/dashboard.
2. Create a programme.
3. Enter the requested identity fields.
4. Save.
5. Confirm that the new programme is selected in the header.

## Next step

Do not create phenotypes immediately. First build the material lineage:
[parents and crosses](04-genetic-material-and-crosses.md).
