# 13 — Selection decisions

BreedOps provides decision support; the breeder remains responsible for the
final decision.

## Scenario

A selection scenario defines the candidate set, traits, selection directions,
data sources and selection proportion.

## MGIDI

MGIDI combines multiple traits into a multi-trait selection framework based on
factor-analytic distances. It requires enough complete candidates relative to
the number of traits.

## MTSI

MTSI is used with multi-trait stability/performance information and requires
compatible WAASBY-derived inputs for the selected traits.

## What the result means

BreedOps may report:

- ranking;
- selected candidates;
- selection differential;
- factor strengths/weaknesses;
- overlap or rank agreement between methods.

These are decision-support outputs. They are not automatically breeding values
or expected additive genetic gain.

See [MGIDI and MTSI](../concepts/mgidi-and-mtsi.md).
