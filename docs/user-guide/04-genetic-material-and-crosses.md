# 4 — Genetic material and crosses

## Parent lines

A parent line represents material used as a parent in a cross. Record the
biological name plus provenance such as accession, source or origin whenever
known.

## Crosses

A cross records the relationship between two parents and the pollination event.

### Workflow

1. Create the female and male parent records.
2. Open **Crosses**.
3. Select both parents.
4. Record the pollination date and relevant notes/status.
5. Save.

BreedOps assigns a stable cross code automatically.

## Why the lineage matters

Later families and seed lots inherit meaning from this chain. Avoid replacing a
parent record with a newly created duplicate merely because its descriptive
metadata changed; update the existing record when scientifically appropriate.

## Archive behavior

Archiving a parent or cross prevents it from being selected for new work, while
preserving existing pedigree relationships.
