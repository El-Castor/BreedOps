# 1 — Getting started

## What you need to know first

BreedOps organizes a breeding programme around linked biological records.
You do not need to understand the database structure. You do need to know
which programme you are working in and what material you are recording.

A normal workflow is:

**programme → parents → cross → family → seed lot → trial/phenotype →
evaluation → analysis → selection decision**

## Sign in

Open the BreedOps URL supplied by your administrator and sign in with your
account. Self-registration is normally disabled. If you cannot sign in,
contact the administrator rather than creating a second identity.

## The active programme matters

Most screens operate in the currently selected programme. Always check the
programme name shown in the application header before entering data.

## BreedOps codes

BreedOps automatically creates stable codes for major breeding records.
Do not try to encode biological meaning into these codes. Use names, accession,
source and notes for meaning; use the code as a stable identifier.

## Archive, do not delete

Scientific history matters. BreedOps therefore archives many records rather
than physically deleting them. Archived ancestors remain visible in existing
lineages, but are not offered for creating new relationships until restored.

## First exercise

For a first controlled test:

1. create one programme;
2. create two parent lines;
3. create one cross;
4. create one family;
5. create one seed lot;
6. record one germination test;
7. configure phenotyping;
8. create one phenotype and one evaluation.

Once you can follow that chain, the rest of BreedOps becomes much easier to
understand.
